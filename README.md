# Mechatronics Quiz App

## What it does

The Mechatronics Quiz App is a Python-based multiple-choice quiz designed for Mechatronics Engineering students. It tests students' knowledge of important topics such as PLC, sensors, actuators, robotics, CNC and CAD. It calculates scores and displays the student's performance.

## How to run it

1. Install Python 3.
2. Download the `mechatronics_quiz.py` file.
3. Open a terminal or command prompt.
4. Run the program using:

```bash
python mechatronics_quiz.py
```

## My Own Twist

I added special features to make the quiz more interactive:

- Students can choose between five and ten questions.
- The application checks invalid answers and asks students to enter a valid option.
- Students can review questions they answered incorrectly after completing the quiz.
